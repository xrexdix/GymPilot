# GymPilot

Trainingsbegleiter als Web-App: Trainingsplan, Geräteeinstellungen (Sitzhöhe usw.), Pausen-Timer
und Geschwindigkeitsmessung (Velocity Based Training) mit dem Handy als Bewegungssensor.

Läuft über GitHub Pages. Die Bewegungssensoren funktionieren nur über https.
Übungslinks für QR-Codes/NFC-Tags: `…/?uebung=<id>`
